Extensions

The following Extensions have been defined as part of the IE Core Implementation Guide. A registry of standard extensions can be found in the FHIR specification, and additional extensions may be registered on the HL7 FHIR registry at http://hl7.org/fhir/registry.

IE Core Profile Extensions

The following extensions are used in IE Core Profiles.

  • IE Core Authentication Time Extension
  • IE Core Ethnicity Extension
  • IE Core Extension Questionnaire URI
  • IE Core Gender Identity Extension
  • IE Core IHI Record Status
  • IE Core IHI Status
  • IE Core IHI Verification Date
  • IE Core Interpreter Required Extension
  • IE Core Medication Adherence Extension
  • Patient Mother's Maiden Name

Other Irish Specific Extension

The following extensions are not used in any IE Core Profile. They are provided to assist implementers who may find them relevant to their specific use cases.

  • IE Core Direct email Extension

IE Core Profile StructureDefinition Extensions

The following extensions are only used in the IE Core Implementation Guide to create IE Core Profiles. They are used in the context of StructureDefinition elements.

  • IE Core IECDI Requirement Extension
