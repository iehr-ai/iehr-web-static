Extension: IE Core Gender Identity Extension

Official URL: http://iehr.ai/fhir/ie/core/StructureDefinition/ie-core-genderIdentity Version: 1.0.0-ballot
Standards status: Trial-use Maturity Level: 3 Computable Name: IECoreGenderIdentityExtension
Other Identifiers: OID:1.3.6.1.4.1.54392.5.2690.42.25

Copyright/Legal: iEHR.ai, all rights reserved Creative Commons License

This extension represents an individual's sense of being a man, woman, boy, girl, nonbinary, or something else, ascertained by asking them what that identity is. Systems requiring multiple gender identities and associated dates SHOULD use the FHIR R5 genderIdentity extension. When future versions of IE Core are based on FHIR R5, the FHIR R5 extension will supersede this extension.

Context of Use

    This extension may be used on the following element(s):

    • Element ID: Patient
    • Element ID: RelatedPerson
    • Element ID: Person
    • Element ID: Practitioner

Profile specific implementation guidance

  • This extension provides concepts to describe the gender a person identifies as. It is not used to describe a person's sexual orientation (who they are attracted to).

  • The concepts included here are from the HL7 Gender Harmony Project, which is modeling gender and sex information data elements, value sets, and code systems.

  • A gender-identity search parameter has been defined for this extension. However, there are no gender-identity search requirements for the client or server.

Usage info

Usage:

  • Use this Extension: IE Core Patient Profile
  • Examples for this Extension: Patient/example-targeted-provenance
